# Security Policy

## Reporting a vulnerability

Please do not report security issues publicly with exploit details or sensitive data. Contact the repository maintainer privately using the contact method listed on the repository profile.

## Important deployment notes

This project is a development/portfolio application and should not be used with real customer or patient data until it has undergone a security review. In particular, add authentication and authorization, protect the demo seed endpoint, validate all incoming data, and review transaction/concurrency behavior before deployment.
